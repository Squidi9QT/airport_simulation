# Имитационная модель аэропорта: регистрация пассажиров

Имитационная модель системы массового обслуживания **M/G/N** на базе `simpy`: регистрация пассажиров в аэропорту через несколько стоек. По результатам серии независимых прогонов строится доверительный интервал для среднего времени ожидания в очереди.

## Модель

- **Входящий поток** — пуассоновский, интервалы между приходами пассажиров экспоненциально распределены (в среднем каждые 2 минуты).
- **Стойки регистрации** — ограниченный ресурс (`simpy.Resource`), очередь FIFO.
- **Время обслуживания** — нормальное распределение (среднее 5 мин, стандартное отклонение 1 мин), снизу ограничено 0.1 мин.

Параметры модели: 3 стойки, коэффициент загрузки ρ ≈ 0.83.

## Статистический анализ

Один прогон модели не показателен, поэтому используется метод независимых прогонов: 30 прогонов с разными seed, из каждого берётся среднее время ожидания. По полученной выборке строится 95%-й доверительный интервал (t-распределение Стьюдента).

## Структура

- `airport_simulation.ipynb` — весь код и анализ: модель, серия прогонов, гистограмма распределения, доверительный интервал.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter notebook airport_simulation.ipynb
```

## Результат

При заданных параметрах (3 стойки, ARRIVAL_RATE=0.5, SERVICE_MEAN=5.0) среднее время ожидания в очереди составляет примерно **2.97 ± 0.53 мин** (95% доверительный интервал).
